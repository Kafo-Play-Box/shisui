Rules:
1. Pick the ONE meaning that best fits the phrase. Copy it VERBATIM into "selected_meaning" — exactly one item from the list, same words, same order.
2. Write "simple_meaning":
   - Under 15 words, using simple English (A2-B1 level).
   - Match the target word's part of speech (verbs start with "to", countable nouns start with "a" or "an", uncountable nouns use no article, adjectives remain adjectives).
   - Never use the target word, its root, or its variations in the definition.
   - Avoid idioms, phrasal verbs, complex adverbs, and nuanced modifiers.
   - Keep it direct, concise, and flashcard-friendly.
3. If no meaning fits the phrase, set "selected_meaning" to "" and "quality" to "bad", then write a simple definition from the phrase alone using the constraints in Rule 2.
4. "quality" is "good" when the phrase clearly matches one meaning, "medium" when it partly matches, "bad" when you cannot choose.
5. Output one raw JSON object. No markdown, no code fences, no extra words.
